# 반딧불 섬 방탈출 — 혼자 연습(학생용)

중학교 2학년 과학 ‘전기와 자기’ 방탈출 게임 「반딧불 섬: 꺼진 등대의 비밀」을 혼자 연습하는 사이트입니다.

- 주소: https://songsamscience.github.io/firefly-practice/
- 시즌1 전기 · 시즌2 자기 중에서 고르고(시즌2만 해도 됩니다), 캐릭터·별명·제한 시간을 정한 뒤 「연습 시작」.
- 역할 4개(탐색가·기록가·분석가·검증가)를 모두 혼자 맡습니다. 정답·해설은 직접 풀어야 보입니다.
- 연습 기록은 그 기기 브라우저에만 저장됩니다(새로고침해도 이어짐). 실제 수업 사이트·선생님 화면과는 관계가 없습니다.
- 위쪽 「연습 메뉴」: 일시정지 · 시간 +10분 · 처음부터 · 처음 화면

제작: 송쌤과학
